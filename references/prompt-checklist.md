# 提示词完整性清单（prompt-checklist）

> 用途：出图前逐段检查提示词。任何一段缺失，先补齐再进参数确认。
> 根因：对话里定过的约束，模型和未来的会话都不会替你记住——遗漏即生成事故。

## 八段结构

1. **资产域声明**：本体还是场景、单张全景还是组合图、排除什么环境；有参考图时声明「外观一律以参考图为准，不另行描述」。
2. **主体描述**：本次主体的有据特征（无参考图时）；有参考图则删重复描述，只留参考图管不到的状态变化（如开合状态）。
3. **比例锁死段**：已定比例数据换算成构图语言——**形状词优先**（近正方形、横向宽矩形），倍数与画面占比兜底（总宽约为总高 N 倍、人头顶落在门高 N% 处），并给反向排除（不得画成蚂蚁大小）。
4. **结构与开合方式段**：可动结构必须显式写运动方式（水平平移/旋转/垂直提升……），并给出反例禁令（不旋转、不绕轴、不向外翻开、不向上提升）。**历史事故：漏写开合方式，反复生成旋转门。**
5. **画风段**：**按场景判定是否必写**——
   - **必写**：从零生图 / 重绘式放大（高清化）/ 换姿态换外观 / 多图合成重绘。这四类都会让模型重画，不钉画风就漂。
   - **可省**：纯蒙版局部重绘、以及只改一处小地方的轻微编辑——底图自带画风，改动范围小、漂移风险低。
   内容只写**渲染语言 + 光照与饱和度基调 + 负向**，模板：
   `电影级写实向 3D CG 渲染，对标《灵笼》的美术质感；阴天漫射光、低饱和、冷峻克制的废土氛围；无 2D 插画感、无动漫赛璐璐风、无油画或水彩笔触。`
   **材质不写进本段**：材质随资产变化，写进各自资产的提示词（本段只定渲染语言，列材质必然挂一漏万）。
   **不做项目级统一色卡**：颜色以参考图 / 入库资产的既有色调为准（同一项目里废土、地堡内部、地球线界面各有色调，统一会失真）。
6. **版式**：组合图只写**必要内容项 + 可发挥项**，不锁死分格数（历史事故：规定五格导致参考绑定被稀释）；或单张全景的前中远景深层次。
7. **排除项**：按本单需要列（无人/无生物/无文字/无环境/无分格线……）。
8. **负向词**：必须包含历史踩过的坑——比例失调、人物过小、人与门比例错误、旋转门/合页/提升门、人形被画进门板、分格拼贴、文字水印。

## 已定设计决策——查证来源

讨论定过的内容必须进提示词，按下表查证：

| 决策类型 | 查哪里 |
|---|---|
| 比例 / 尺寸 | `资产/尺寸基准.md` |
| 形象特征 / 锚点卡 | asset-prompt-generator 输出的形象描述卡；`小说/设定/` |
| 结构与开合方式 | 小说正文（有据）；对话中用户拍板的（须同时核对正文是否已同步） |
| 正反面特征、本体/场景域分工 | 对话拍板记录；`资产/README.md` |
| 参考图分工 | 用户指定哪张参考图管什么（外观/结构/比例） |

**有据 vs 推断**：工程文本没有、靠推理补的细节（如啮合机构形态），在提示词里标注「推断项」，不混充设定。

## 输出前自检

- 提示词**自包含**：脱离对话单独看，仍含全部已定约束？
- 参考图负责的部分已声明「以参考图为准」，文字未与之冲突？
- 八段齐全、负向词含本资产踩过的坑？

## 官方 prompting 铁律（来源：heyroute 官方 skill 仓库的 `image-gen/references/prompting.md`，非本目录文件）

- **结构顺序**：场景/背景 → 主体 → 细节（材质/光线/配色）→ 约束（必须保留 / 禁止出现）。
- **改图必须显式列不变量**：「只改 X；Y、Z 保持不变」，**每一轮迭代重复**，防漂移；**一次只改一处**。
- 用户描述已具体就只规整不加戏；很泛才补构图/光线/用途，不添加用户没暗示的元素。
- 说明用途；写实照片用相机语言（焦段/景别/光线）。
- 图内文字用引号逐字给出并指定位置；文字多必乱，能不放就不放。
- `n` 恒为 1：多素材 = 多次调用，别指望一次出全套。
- 图标/线框/矢量类资产别生图，直接写 SVG/CSS 更可控。
